# Seva Connect Guidelines

Seva Connect is an NGO & Non-Profit Beneficiary Management System built with React 19, TanStack Start & Router, Tailwind CSS v4, and Supabase.

### Conventions
- **TypeScript**: Strict type adherence across routes, components, and models.
- **Styling**: Tailwind CSS v4 utilities with harmonious semantic colors.
- **Database**: Supabase PostgreSQL with Row Level Security (RLS) policies.
